# 🎮 미니 게임 상자

브라우저에서 바로 돌아가는 캐주얼 퍼즐 두 편. 빌드 도구도, 외부 라이브러리도 없이 순수 HTML + Canvas + JavaScript로만 만들었습니다.

| 파일 | 게임 | 설명 |
|---|---|---|
| `index.html` | 런처 | 두 게임 진입 + 저장된 진행·코인 표시 |
| `merge-game.html` | 🍹 비치바 머지! | 음료를 튕겨 쏘고 같은 음료끼리 합치는 물리 머지 퍼즐 |
| `screw-game.html` | 🔧 나사 풀기! | 겹쳐진 조각에서 나사를 색깔별로 빼내는 레이어 퍼즐 |

## 실행

`index.html`을 브라우저로 열면 끝입니다. GitHub Pages에 올리려면 Settings → Pages → Source를 이 브랜치의 루트로 지정하면 됩니다.

## 비치바 머지!

- 아래 음료를 드래그해 조준하고 놓으면 발사 (벽 반사까지 계산한 궤적 미리보기)
- 같은 음료끼리 부딪히면 한 단계 위로 합쳐짐 — 에스프레소부터 전설의 칵테일까지 9단계
- 위쪽 **손님이 주문한 음료**를 만들면 자동 서빙, 인내심이 남아 있을수록 팁이 붙음
- 인내심이 다 떨어져 손님이 떠나거나, 점선 아래에 음료가 멈추면 ❤️ 감소
- 30스테이지 · 별 3개 평가 · 부스터(폭탄 / 승급 / 여유)

## 나사 풀기!

- 나사를 탭하면 풀려서 같은 색 홀더로 이동, 한 홀더에 같은 색 3개를 모으면 사라짐
- 맞는 홀더가 없으면 임시 트레이(5칸)로 가고, 트레이가 막히면 실패
- 위 조각에 덮인 나사는 잠김 — 위 조각을 먼저 떼어내야 함
- 조각의 핀이 0이면 떨어지고, 1개만 남으면 그 나사를 축으로 흔들림
- 40스테이지 · 오브젝트 6종(풍선 다발 · 곰인형 · 꽃 · 아이스크림 · 로켓 · 자동차) · 부스터(홀더 추가 / 되돌리기 / 색 변경)

## 저장

진행·별·코인·아이템은 브라우저 `localStorage`에만 저장됩니다. 코인과 아이템은 두 게임이 함께 씁니다.

| 키 | 내용 |
|---|---|
| `mergeSave` / `screwNutsSave` | 각 게임의 해금 스테이지·별·최고점 |
| `gameWallet` / `gameItems` | 공용 코인 지갑과 부스터 보유량 |

런처 하단의 "게임 기록 초기화"로 전부 지울 수 있습니다.

## 그림 교체

모든 그림은 코드로 그린 벡터라 파일이 없어도 동작합니다. PNG/SVG로 바꾸려면 `assets/sprites.js`에 경로만 채우면 되고, 파일이 없는 항목은 자동으로 벡터로 되돌아갑니다. 규격은 [`assets/README.md`](assets/README.md) 참고.
