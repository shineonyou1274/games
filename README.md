# 🎮 미니 게임 상자

브라우저에서 바로 돌아가는 캐주얼 게임 다섯 편. 빌드 도구도, 외부 라이브러리도 없이 순수 HTML + Canvas + JavaScript로만 만들었습니다.
홈 화면에 설치하면 앱처럼 열리고, 한 번 열어 본 게임은 **오프라인에서도** 실행됩니다.

| 파일 | 게임 | 설명 |
|---|---|---|
| `index.html` | 런처 | 게임 목록 · 전체 집계 · 태그 필터 · 설치 버튼 |
| `merge-game.html` | 🍹 비치바 머지! | 음료를 튕겨 쏘고 같은 음료끼리 합치는 물리 머지 퍼즐 |
| `screw-game.html` | 🔧 나사 풀기! | 겹쳐진 조각에서 나사를 색깔별로 빼내는 레이어 퍼즐 |
| `prime-hunter.html` | 🚀 프라임 헌터 | 숫자가 적힌 적기 중 소수만 격추하는 학습형 슈팅 |
| `recycle-runner.html` | ♻️ 쓰담쓰담 러너 | 달리며 쓰레기를 줍고 4종으로 분리배출하는 러너 |
| `duel.html` | ⚔️ 맞짱 두뇌대결 | 한 기기를 반으로 나눠 둘이서 겨루는 O/X 대결 |

## 실행과 설치

`index.html`을 브라우저로 열면 끝입니다.
웹에 올린 뒤(예: GitHub Pages) 접속하면 런처에 **홈 화면에 설치하기** 버튼이 뜨고, 설치하면 주소창 없는 앱처럼 열립니다.
설치하지 않아도 한 번 방문한 파일은 서비스워커가 캐시해 두어 네트워크 없이 동작합니다.

## 비치바 머지!

- 아래 음료를 드래그해 조준하고 놓으면 발사 (벽 반사까지 계산한 궤적 미리보기, 키보드 ←→ 조준 / Space 발사)
- 같은 음료끼리 부딪히면 한 단계 위로 — 에스프레소부터 전설의 칵테일까지 9단계
- 위쪽 손님이 주문한 음료를 만들면 자동 서빙, 인내심이 남아 있을수록 팁이 붙음
- **👑 VIP 손님**(8스테이지부터)은 보상이 2배지만 인내심이 짧음
- 3~5발마다 음료가 한 줄 밀려 내려오고, 점선 아래에 멈추거나 테이블이 가득 차면 실패
- 40스테이지 · 별 3개 평가 · 부스터(폭탄 / 승급 / 여유)

## 나사 풀기!

- 나사를 탭하면 같은 색 홀더로 이동, 한 홀더에 같은 색 3개를 모으면 사라짐 (키보드 방향키로 선택 / Enter로 풀기)
- 맞는 홀더가 없으면 임시 트레이(4칸)로 가고, 트레이가 막히면 실패
- 위 조각에 덮인 나사는 잠김 — 위 조각을 먼저 떼어내야 함
- 조각의 핀이 0이면 떨어지고, 1개만 남으면 그 나사를 축으로 흔들림
- 60스테이지 · 오브젝트 **9종**(풍선 다발 · 곰인형 · 꽃 · 아이스크림 · 로켓 · 자동차 · 고양이 · 나비 · 집) · 부스터(홀더 추가 / 되돌리기 / 색 변경)

## 프라임 헌터

- **← →** 이동, **스페이스** 발사 (모바일은 화면 아래 버튼)
- 소수가 적힌 기체만 맞히면 점수와 콤보가 오르고, 아니면 감점 + 그 수의 **소인수분해**가 표시됨
- 끝나면 정확도·등급과 함께 맞힌 소수 / 잘못 쏜 합성수 / 놓친 소수를 목록으로 정리
- 난이도 4단계 (2~50 · 2~100 · 2~200 · **지옥 2~300**), **P** 일시정지, **M** 소리 전환

## 쓰담쓰담 러너

- **Space** 또는 화면 탭으로 점프, 장애물은 피하고 반짝이는 쓰레기를 주움
- **25점마다 수거차가 도착** — 주운 쓰레기를 플라스틱 · 종이 · 캔 · 유리 네 통에 나눠 담음
  (항목을 눌러 고른 뒤 통을 누르거나, 통 위로 끌어다 놓기. 키보드는 **1~4**)
- 한 번도 틀리지 않고 정리하면 하트가 하나 회복되고, 끝나면 별 1~3개로 채점
- 점수 = 달린 시간 + 주운 개수×5 + 정확히 분류×10 − 잘못 분류×3

## 맞짱 두뇌대결 (2인용)

- 기기를 가운데 두고 **마주 앉아** 플레이 — 위쪽 화면은 180° 뒤집혀 있습니다
- 가운데 문제가 뜨면 맞으면 **O**, 아니면 **X**. **먼저 누른 쪽만** 판정하고, 맞으면 1점 / 틀리면 상대 1점
- 문제가 뜨기 전에 누르면 **부정 출발**로 상대에게 1점
- 문제 종류를 고를 수 있음 — 소수 · 짝수/배수 · 계산 · 비교 · 분리배출, 3·5·7점 선승 선택
- 키보드: 플레이어1 **A**(O)/**S**(X), 플레이어2 **K**(O)/**L**(X)

## 저장

진행·별·코인·전적은 브라우저 `localStorage`에만 저장됩니다. 코인과 부스터는 머지·나사 게임이 함께 씁니다.

| 키 | 내용 |
|---|---|
| `mergeSave` / `screwNutsSave` | 머지·나사 게임의 해금 스테이지·별·최고점 |
| `primeBest` / `recycleBest` | 프라임 헌터 · 쓰담쓰담 러너 최고 점수 |
| `duelStats` / `duelCats` / `duelTarget` | 대결 전적과 설정 |
| `gameWallet` / `gameItems` | 공용 코인 지갑과 부스터 보유량 |
| `gamePlays` | 게임별 플레이 횟수와 마지막 플레이 시각 (런처 집계용) |

런처 하단의 "게임 기록 초기화"로 전부 지울 수 있습니다.

## 구조

```
index.html              런처 — assets/core.js의 게임 목록을 읽어 카드를 그린다
assets/core.js          공용 코어: 저장소 · 지갑 · 사운드 · 스프라이트 로더 · 게임 목록 · PWA 등록
assets/sprites.js       스프라이트 매니페스트 (그림 교체 지점)
assets/drinks/*.svg     음료 9종
assets/screws/*.svg     나사 8색
manifest.webmanifest    설치 정보(이름·아이콘·색)
sw.js                   서비스워커 — 문서는 네트워크 우선, 그 외는 캐시 우선
```

새 게임을 추가하려면 HTML 파일을 하나 놓고 `assets/core.js`의 `GAMES` 배열에 한 줄 더하면 런처에 바로 나타납니다.

## 그림 교체

음료 9종과 나사 8색은 `assets/` 안의 **SVG 파일**을 씁니다. 손님 얼굴과 나사 게임 조각은 코드로 그린 벡터입니다.
어느 쪽이든 `assets/sprites.js`에 경로만 채우면 그림이 교체되고, 파일이 없는 항목은 자동으로 벡터로 되돌아갑니다.
규격과 목록은 [`assets/README.md`](assets/README.md) 참고.
