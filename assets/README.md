# 스프라이트 가이드

현재 `drinks/`(음료 9종)와 `screws/`(나사 8색)는 **SVG 아트가 들어 있고 게임이 이미 그걸 씁니다.**
`customers`(손님 얼굴)와 `parts`(나사 게임 조각)는 아직 비어 있어 코드로 그린 벡터가 나옵니다.
아래 방법으로 언제든 다른 그림으로 갈아끼울 수 있습니다.

---


`assets/sprites.js`의 값만 채우면 게임 코드를 건드리지 않고 그림을 바꿀 수 있습니다.
값이 비어 있거나 파일을 못 찾으면 **자동으로 기존 벡터 드로잉으로 되돌아갑니다.**
그래서 일부만 교체해도 게임은 정상 동작합니다.

## 넣는 방법

1. 이미지 파일을 `assets/` 안에 둡니다. (하위 폴더 사용 가능: `assets/drinks/espresso.png`)
2. `assets/sprites.js`에서 해당 키에 `base` 이후의 상대 경로를 적습니다.

```js
drinks: {
  0: 'drinks/espresso.png',
  1: 'drinks/icetea.png',
  ...
}
```

3. 브라우저 새로고침. 끝.

## 규격

| 용도 | 권장 크기 | 배경 | 기준점 |
|---|---|---|---|
| `drinks` (음료 9단계) | 256×256 PNG | 투명 | 잔이 정사각형 중앙, 아래쪽 여백 최소 |
| `customers` (손님 얼굴) | 256×256 PNG | 투명 | 얼굴 중앙 정렬 |
| `screws` (나사 머리) | 128×128 PNG | 투명 | 원형 나사머리가 꽉 차게 |
| `parts` (조각) | 자유 (가로형 512×256 등) | 투명 | 조각의 바운딩 박스에 맞춰 늘어남 |

- 형식은 PNG / WebP / SVG 모두 됩니다. 애니메이션 GIF는 첫 프레임만 나옵니다.
- 그림자·반짝임 같은 효과는 게임이 이미지 뒤에 따로 그리므로 **그림자를 굽지 말고** 오브젝트만 그려 주세요.
- `parts`는 이미지가 조각 크기에 맞춰 늘어나므로, 조각 비율(가로:세로)에 맞춘 그림이 자연스럽습니다.

## 지금 들어 있는 파일

| 경로 | 내용 |
|---|---|
| `drinks/0-espresso.svg` … `8-legend.svg` | 머지 게임 음료 9단계 |
| `screws/red.svg` … `cyan.svg` | 나사 머리 8색 |

`parts`는 조각마다 크기·비율이 달라 코드로 그리는 편이 자연스러워 비워 두었습니다.
바꾸고 싶으면 스타일 이름(`balloon`, `basket`, `fur` …)에 이미지를 지정하면 조각 크기에 맞춰 늘어납니다.

## 파일이 없을 때

`sprites.js`에 적은 경로에 파일이 없으면 콘솔에 404가 한 번 찍히고 그 항목만 벡터로 대체됩니다.
아예 요청을 막고 싶으면 값을 `''`로 되돌리면 됩니다.
